# cs-app-low-cortisol

> A low-cortisol approach to Computer Systems: A Programmer's Perspective.

## What is this?

This is my personal war journal for CS:APP. I'm reading the book, doing the labs, and writing anchor notes that connect everything to modern hardware (GPUs, inference engineering, compilers). You can copy this repo structure if you want tho.

## How to use this repo

1. Read the book. The PDF is widely available if you know where to look.
2. Download the labs from the official CS:APP website: https://csapp.cs.cmu.edu/3e/labs.html
3. Extract them into `labs/`.
4. Follow `PROGRESS.md`.
5. Write anchor notes in `notes/`.

## The Rules

1. No day estimates. I go at my own pace.
2. No cargo culting. I understand every line I write.
3. Anchor notes are mandatory. If I can't connect it to something real, I don't understand it.
4. Commits should be funny. If the commit message isn't at least a little unhinged, I'm not having fun.
